# SLOPE WRITER — 式の坂でボールを転がす

式を入れると、そのグラフが坂になる。ボールを転がして、浮かんだ点を全部拾わせるパズル。直線・放物線・sin の波を使い分けて、全 12 ステージ。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/slope-writer/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 下のキーで式を入れて「この式で引く」。そのグラフが線になる（例: `-x` で右下がりの坂）。
2. 「スタート」でボールが落ちて、線の上を転がる。
3. 浮かんでいる点に全部ふれたらクリア。落ちたり止まったりしたら、式を直してもう一度。

- 「y =」を押すと「x =」に替わる（`x = 4` は縦の線）。「範囲」で線を途中で終わらせられる。
- 引いた式はチップに並ぶ。押すと直せる。✕ か長押しで消す。⌫ の長押しで入力を全部消す。
- 引いた本数が目標以内なら ★3、1 本多いと ★2、それより多いと ★1。
- 同じステージで 3 回失敗すると「解答例」が出る（見てクリアしたら ★1）。
- 書ける式: 数、`x`、`pi`、`e`、`+ - * / ^`、かっこ、掛け算の省略（`2x`、`3(x+1)`）、`sin cos tan sqrt abs exp ln log floor min max`
- PC: キーボードでそのまま打てる（全角も可）。Enter で引く、Space でスタート / 止める、Esc で入力を空にする。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 式の読み取りとステージの自己チェック（30 秒ほど）
```

| ファイル | 中身 |
|---|---|
| `parser.js` | 式の読み取り（字句 → 構文 → 関数。`eval` は使わない） |
| `physics.js` | 式を線（折れ線と当たり判定）にする、物理（1/480 秒の決まった刻み）。調整つまみは先頭 |
| `stages.js` | 12 ステージと想定解 |
| `main.js` | 画面・キーパッド・描画・音・保存 |
| `test.mjs` | 読み取りの表、全ステージを想定解・±0.05 ずらし・直線の総当たり・代表的な式 1 本・30/60/120Hz で走らせるチェック |

- ステージを足したら `node test.mjs` を通す。ゴールは想定解で転がした道の上に置く（±0.05 ずらした走りもすべて通る所）。
- 保存: `slope-writer.settings`（音）、`slope-writer.progress`（クリアと星）、`slope-writer.work`（ステージごとの書きかけの式）。
